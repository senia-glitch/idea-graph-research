# Исследование

Пакет-скилл с веб-поиском. Ищет конкурентов и факты, добавляет их карточками с источниками,
подтверждает или опровергает допущения. Если факт спорит с принятым решением — задаёт вопрос.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
