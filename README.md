# Этап «Разведка» (idea-graph-recon)

Сфера → список конкурентов → анализ → **общий банк проекта**. Остальные этапы читают банк (`competitors`, `analysis`).

| Шаг | Что происходит |
|---|---|
| Сфера | Вы пишете сферу бизнеса, подлежащую автоматизации (можно несколько) |
| Конкуренты | Три исследователя на разных моделях ищут реальных конкурентов и аналоги; агент сводит (берёт найденное двумя или со ссылкой) и записывает в банк; вы правите список и утверждаете |
| Анализ | По каждому принятому конкуренту один исследователь собирает роли в системе, бизнес-процессы и уникальные фичи; агент сверяет и записывает в банк |

Записанное агентом остаётся «предложенным»: принимаете вы. Источники (ссылки) хранятся в записях. В автоматическом режиме без вашего
участия анализируются предложенные конкуренты. Потолок списка конкурентов — в «Настройках» (по умолчанию 6).

Весь код — декларация этапа (`manifest()`): шаги, банки, промпты и задания исследователям; механику выполняет `idea-graph-engine`.
